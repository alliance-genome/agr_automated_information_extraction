# Rules for every WB data type

A paper is positive for a data type only when it reports its OWN new experimental results of that type, obtained in
C. elegans (or another Caenorhabditis / free-living nematode that WormBase curates) or with C. elegans genes and gene
products.

It is NOT positive when the only content of that type is:
- results cited from other papers (introduction, discussion, "previously described", "data not shown" from others);
- a review, commentary, book or WormBook chapter, database or resource description, erratum, correction or
  corrigendum, or a retracted paper;
- a methods, protocol or technique paper whose experiments only demonstrate the method;
- computational predictions, simulations, structure modelling or orthology comparisons without experiments;
- experiments only in other organisms: mammals, Drosophila, yeast, plants, cell lines, bacteria or pathogens (a
  bacterial or pathogen mutant is not a worm allele), or C. elegans genes studied only in a heterologous system when
  the data type requires worm data (see each type).

Mentioning a topic in passing, in a list of keywords, or in the discussion is not data.
